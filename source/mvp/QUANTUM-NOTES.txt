SPINDOCTOR 3.0.4 - FAMILY MODEL AND SELECTED REGISTERS

BOOT.cmd verifies the TIFF/GIF filesystem and launches its contained quantum
program. The three core artifacts remain the TIFF, GIF and generic C# evaluator;
BOOT.cmd is a convenience launcher. The images contain equivalent filesystems.

The default family has M=20,000,000 and L=25,000,000, yielding exactly
500,000,000,000,000 virtual state addresses. At migration t=1, every index
defines a distinct mathematical single-qubit pure state. At t=0 all addresses
start at |0>. Local gates preserve coherence through a composed 2x2 matrix.
The q.prepare/q.migrate/q.gate/q.state/q.measure/q.verify family commands
describe independent single-qubit states, without family-wide entanglement.
The separate q.tranche and q.circuit commands calculate joint entangled states
inside one selected coherent register of up to 29 qubits, subject to memory limits.

For k=a+M*b, p=(a+0.5)/M, phi=2*pi*b/L and theta=2*asin(sqrt(p)).
The state is G*[cos(t*theta/2), exp(i*t*phi)*sin(t*theta/2)].
U(theta,phi,0) prepares the target at t=1. RY followed by RZ has the same
state up to global phase. Gate accounting uses explicit terminal commits.
Point queries, verification and measurements earn no represented gate credit.

The C# module performs real FP64 CPU and OpenCL GPU calculations. No Python,
NumPy, cloud service or quantum hardware is required. The primary terminal uses
Windows/.NET Framework and Windows PowerShell. CPU commands work without a GPU.
Actual CPU/GPU sample comparison requires an installed FP64-capable OpenCL GPU
driver. A GPU failure is reported explicitly and is not replaced by a fabricated
GPU result.

The rule checks establish mathematical normalization, unitary composed gates
and the indexed grid properties. Actual implementation checks compare selected
GPU states with CPU reference amplitudes, normalization, Born probabilities
and all three Bloch components. A sample PASS is not a full-domain memory scan.

Only failed per-state checks are written to the error log. Aggregate counts,
timings, source identities, descriptor state and replay information persist.
Sampling and measurement seeds are preserved across runs. Measurements are
seeded classical draws from Born probabilities; they are not physical shots.

The prior approximately one-second verification of 10,252 states is a target
reference, not a guaranteed boot time or 500-trillion executed gate rate.
The terminal reports its newly measured timings separately from model counts.
