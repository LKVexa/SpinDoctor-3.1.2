The contained state equation

N = M × L; 0 ≤ address < N
k = address mod M; ℓ = floor(address / M)
θ = 2 asin √((k + ½) / M); φ = 2πℓ / L; 0 ≤ t ≤ 1
|ψ(address,t)⟩ = G · [cos(tθ/2), exp(i tφ) sin(tθ/2)]ᵀ
G ← gate × G; initially G = identity
⟨X⟩ = 2 Re(α*β); ⟨Y⟩ = 2 Im(α*β); ⟨Z⟩ = |α|² − |β|²

At t = 1, the default grid gives 500 trillion distinct independent state preparations before a shared unitary. G preserves complex amplitudes and overall phase. The indexed family supports shared single-qubit gates. Selected coherent registers and circuit programs use the contained joint-state backend for entangling gates.

Accounting conventions

U preparations and shared gate applications count represented logical actions. The preparation rotation equivalent uses two rotations per U preparation, up to overall phase; it is a decomposition convention. CPU/GPU state calculations, verification points, sampled shots and wall-clock times are measured separately. The displayed amplitudes retain the engine's phase convention.

Input format schemas and workflow
JSON circuit

name, qubits (1–298), initialBasis, parameters, ordered gates. Each gate has name, angles, qubits and all. Evaluate bindings, then import, then run.

OpenQASM 2

One qreg, standard gates, optional complete final Z measurements. Includes are symbolic built-ins. Unsupported gate definitions and mid-circuit measurement return errors.

TXT command input

An explicit q.circuit new/input/add script. Parse and inspect its circuit description; uploading text never executes arbitrary terminal commands.

CSV gate-list circuit

Use a gate,n,targets,angles header. Declare n (1–298) in the first gate row; gate operands are ordered, with controls before targets. Optional name, initialBasis, shots and basis metadata can be declared once or repeated consistently. A comma-separated target or angle list is one quoted CSV field, such as "0,1" or "pi/4,0,pi". The native parser checks each gate and its safe angle expressions.

CSV numeric data

One header row and numeric measurement rows, including weather or gate/circuit observations. Inspect native columns, choose the target and input columns, then fit explicitly. A table of observations is distinct from an explicit gate-list circuit. The empirical linear equation and fit quality are reported in TXT, PDF and CSV. Fitting does not run quantum shots.

CSV sweep

Parameter-name header and safe expressions. Select a stored base circuit and a row (starts at 0), evaluate, and import deliberately.

PDF equations

A PDF must embed one UTF-8 JSON/QASM/TXT/CSV file, or contain explicit SPINDOCTOR-JSON-BEGIN / SPINDOCTOR-JSON-END text markers (QASM/TXT/CSV also accepted). Inspect native extraction and validate before importing. Extraction supports plain or Flate-compressed embedded files and explicitly tagged text in the supported PDF subset. Arbitrary PDF layouts and scanned pages require transcription; no OCR runs, and explanatory prose is never converted into execution automatically.
