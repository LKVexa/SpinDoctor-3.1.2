Direct circuit commands

Gate operands belong to the selected circuit. q.migrate changes the procedural
family descriptor and does not enlarge that circuit. Invalid operands now report
the circuit name, valid range, offending indices and required minimum width.

Execution scope
298 is the logical register width. One joint coherent tensor factor supports
at most 59 qubits, subject to the memory budget; a merge exceeding that limit is
rejected. This record uses a 42-qubit correlated factor and 256 fixed hash bits.
Global indices and result strings preserve all 298 bits without integer wrapping.
Circuits of 1..29 qubits retain shot replay and their original measurement modes.
Wider circuits prepare once and sample joint factors in Z. This is a classical
FP64 simulation; a full arbitrary dense 2^298 state vector is not allocated.
Auxiliary analysis commands retain their own bounded limits.

Verification and records
verify=true checks sampled procedural predictions on the CPU and actual OpenCL
GPU after each file. It is separate from the exact native record-amplitude audit
and from circuit sampling; it does not establish quantum-hardware execution.
purge=true releases temporary coherent outputs after native archive capture.
Full histogram records, saved programs, source files, seeds and history remain.

The normal launcher verifies and decodes the updated TIFF/GIF carrier. The static
installation update excludes SpinDoctor\workspace. On restart BOOT refreshes
carrier-listed code and demonstration files; unlisted mutable session, checkpoint,
input and archive files survive. Pre-update static and workspace backup ZIPs are
saved in the Codex chat outputs folder. Historical PDFs and audits retain the
